An entry for make.fun's **Sum up 17 November 2026's world news in one image** bounty.

A 1024x1024 poster of seven stories from Tuesday 17 November 2026: the Shenzhen
trilateral summit confirmed, a tanker burning in the Strait of Hormuz, protests
in Manila, Iran refusing UN inspection, Nvidia named a national champion, 40
Amazon Leo satellites lost, Robert Pattinson as Bond.

`main.ts` copies `entry.png` to `/output/entry.png`, checking the 1 MiB size cap
and the PNG signature before it reports success.

Run locally:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
